# 六媒介適配提案

## 13. 六媒介適配規格（全部為P）

此節是執行提案，不新增原圖硬規則。每次任務只需處理所選媒介，不要求一次生成54個作品。

| 媒介 | 保留內容 | 需新增的任務規格 | 驗收證據 |
|---|---|---|---|
| 圖片 | 配色角色、字體角色、構圖識別、禁用項目 | 尺寸、比例、字數、Logo素材、輸出格式 | 成品目視、文字比對；若可取得則核對生成／排版設定 |
| 簡報 | 色票、標題與內文字體、元件語言 | 16:9或指定比例、頁型、可編輯要求、圖表規格 | 開啟檔案、抽查文字可編輯、逐頁檢查溢出 |
| 文件／文字 | 標題階層、強調方式、品牌用語 | A4或指定頁面、表格、長文、列印；純文字無法呈現的視覺項目標N/A | 排版預覽、內容完整性；純文字不判材質合格 |
| 互動網頁 | 配色與元件外觀、核心構圖 | 手機尺寸、斷點、focus/disabled/error/loading、鍵盤操作、資料行為 | 實際操作與不同視窗截圖，避免只有外觀示意 |
| 動畫 | 主視覺識別與色彩節奏 | 時長、曲線、進出場、減少動態版本 | 播放檢查、時間軸與文字停留可讀性 |
| 影片 | 品牌視覺、字幕字體角色、場景一致性 | 分鏡、片長、字幕安全區、音訊、片頭尾 | 播放與逐段檢查；數據來源不因剪輯被裁掉 |

### 各風格適配邊界（P）

- AS-001：直排保留在標題區，長文與操作說明採橫排；橫式構圖另設比例，不硬套1/4寬。
- AS-002：五段骨架可轉成網頁區塊或簡報區域；玻璃效果須以可讀性為前提，不憑「精品感」加金。
- AS-003：錶盤與刻度可用於資料視覺，但裝飾刻度不得冒充真實量測；17°為圖面方向，不能直接當CSS角度值。
- AS-004：貼紙視覺可延伸至互動按鈕，按壓動態需另定；白邊與陰影不可讓文字顯得模糊。
- AS-005：雙環進度需各有標籤、分母與狀態；健康數字的意義由任務資料決定。
- AS-006：簡報與文件保留綠框和中軸識別；長文是否可局部左對齊屬新增適配，不直接覆蓋原圖的全頁對稱規則。
- AS-007：網頁可用區塊序代替頁序，但須明示此為新解讀；細線與細字在實際顯示尺寸檢查。
- AS-008：所有主張與來源保持關聯；1:1裁切不能裁掉註腳，應重排；動畫數字不能脫離來源獨立播放。
- AS-009：縫線框隨畫幅調整，但維持內縮和圓角關係；長文字放奶油麻卡片，不把字縮到橙底規則以下。
