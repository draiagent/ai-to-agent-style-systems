最低檢查範圍：

1. 文字與內容：中文正確、名稱不變、必要內容齊全、數據有來源或清楚佔位。
2. 視覺：配色角色、字體角色、構圖、元件、禁用項目與所選AS相符。
3. 適配：說明媒介尺寸與原圖基準的關係；不得用縮小整張圖代替可讀排版。
4. 功能：要求可編輯就實際開啟檢查；網頁就操作；動畫／影片就播放。
5. 未決：相關Q項列明，未測項目不標PASS；有例外不標「完全遵循」。

數值驗收限制：色碼可用實作設定檢查；合成圖片像素受光影影響。色彩面積百分比須待Q-G02定義後量測。字型缺失不能只看近似外觀判PASS。AS-002的4.5:1須針對實際文字與合成背景量測，未量測則未驗證。
