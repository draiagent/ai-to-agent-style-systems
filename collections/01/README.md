# AS Collection 01｜九套設計系統

## 本批介紹

第一批建立 AS 系列的基礎，將九種視覺風格整理為有來源的設計規格與 Agent 指令。本批 AS-001～AS-009，包含 63 張來源圖、10 張介紹圖卡與 13 項未決事項。
