版本：v0.1｜日期：2026-10-08｜狀態：來源轉錄與規格整理稿，含未決項目；Repo整合版本0.1.0

AS：Agent Style。專案名稱：ai-to-agent-style-systems。此文件不代表 GitHub 已建立或發布，也不代表跨媒介生成已通過驗證。

## 1. 使用範圍與證據標記

本文件依九份原始 ZIP、共 63 張 PNG 整理。九份 ZIP 均通過解壓縮 CRC 檢查，均各有七張 PNG；所有 PNG 實際尺寸為 2160×2700。多套圖卡文字另指定 1080×1350 作為 4:5 設計輸出基準，兩者須分開記錄。

本文件把原圖內容整理成可執行條目，並非逐字逐句逐字稿。色碼採圖卡文字值，不以漸層像素反推；字型名稱採圖卡標示，不代表已取得字型檔或授權。

| 標記 | 意義 | Agent 如何使用 |
|---|---|---|
| E | 原圖明訂的文字、數值或名稱 | 在適用範圍內遵守；如有衝突須連同 Q 項處理 |
| O | 原圖可見的視覺觀察 | 作為參考，不可宣稱有未記載的精確參數 |
| P | 本次新增的執行、適配或驗收提案 | 可供試作；不得冒充原作者明訂規範 |
| Q | 衝突、語意不清或缺失 | 保留未決狀態；涉及該項的驗收不得直接判 PASS |

來源格式 `AS-001/P02` 指來源索引中的第二張圖。規則 ID `001-R01` 永久對應該風格的一項規格；後續修改應保留 ID 與變更紀錄。表格中同一條包含多個相關數值時，驗收應逐項檢查，不可只檢查其中一項。

5. 未決：相關Q項列明，未測項目不標PASS；有例外不標「完全遵循」。

數值驗收限制：色碼可用實作設定檢查；合成圖片像素受光影影響。色彩面積百分比須待Q-G02定義後量測。字型缺失不能只看近似外觀判PASS。AS-002的4.5:1須針對實際文字與合成背景量測，未量測則未驗證。
